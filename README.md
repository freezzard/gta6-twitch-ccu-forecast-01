Forecasts the Twitch viewers of Grand Theft Auto VI in each hour of its release day, as five quantiles per hour, from the first hour's print and the recorded curves of past big game launches. The median and spread of each hour come from the weighted log-ratios of comparable launches, shrunk toward a persistence prior where the data is thin.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
